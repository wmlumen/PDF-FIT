Estructura de Perfiles

Cada perfil tiene un alcance, herramientas y visión distintos. La plataforma se adapta al rol para que cada usuario vea solo lo que necesita.

Acceso: La plataforma está disponible mediante:

📱

Aplicación Móvil (PWA)

Instalable en cualquier dispositivo. Funciona offline. Sincroniza automáticamente al recuperarse la conexión.

💻

Interfaz Web

Acceso directo desde navegador. Sin instalación requerida. Ideal para computadoras y tablets.
