Clases 11 a 14 • Fase de Proyecto Integrador Contable

🎯 Objetivos del Proyecto

  • Implementar un sistema de información contable completo para una empresa ficticia.
  • Garantizar cumplimiento legal (Res. 412/04) y técnico (Excel/Word).
  • Presentar un Dictamen de Auditoría de Sistemas sobre la implementación realizada.

🗓️ CRONOGRAMA DE ENTREGABLES

Hito 1 (Clase 11): Definición de Empresa y Plan de Cuentas Maestro.
Hito 2 (Clase 12): Carga transaccional, Asientos Automáticos y Conciliación.
Hito 3 (Clase 13): Reportes Gerenciales y Dashboard Financiero.
Hito 4 (Clase 14): Defensa del Proyecto y Dictamen Final.

📖 CONCEPTOS A APLICAR

Durante estas semanas, el alumno actúa como **Consultor de Sistemas Contables**. Se evalúa no solo el "qué" (el balance) sino el "cómo" (integridad de los datos, uso de fórmulas complejas, estandarización de reportes).

🧠 GLOSARIO DEL PROYECTO

  • MIGRACIÓN: Proceso de pasar datos de un sistema manual al digital.
  • INTERFAZ: Conexión entre el módulo de ventas y el módulo contable.
  • VALIDACIÓN: Pruebas de fuego para asegurar que los activos igualan a los pasivos + patrimonio.
