1. Conceptos Fundamentales

1. AUDITORÍA DE PROGRAMAS Conjunto de técnicas para asegurar que el código fuente y la lógica de los algoritmos procesan los datos según las normas legales y operativas.
Ejemplo contable: Verificar que el cálculo del IVA 10% se aplique sobre el Neto Gravado y no sobre el Total Bruto en el módulo de facturación.
2. AUDITORÍA DE OPERACIÓN Evaluación de los controles que aseguran que el hardware y los sistemas operativos funcionan correctamente durante el procesamiento diario.
Ejemplo contable: Verificar si el servidor realizó el cierre de caja a las 20:00 hs sin errores de base de datos.
3. BACKUP (COPIA DE SEGURIDAD) Proceso de duplicación de datos en medios físicos o lógicos para garantizar la recuperación ante desastres.
Ejemplo contable: Sincronización diaria del archivo Maestro de Clientes en un almacenamiento Cloud cifrado.

2. Glosario Técnico de la Unidad

LOG de Auditoría
Registro cronológico de quién realizó cada acción en el sistema.
SDLC
Ciclo de vida de desarrollo de software (etapas de creación).
Hash MD5
Algoritmo para verificar que un archivo no ha sido alterado.
Control de Segregación
Garantizar que quien crea el proveedor no sea quien le paga.
