2. Blindaje de Modelos Financieros

2.1 Referenciación Absoluta ($) y Nombres de Rango

Un error común en auditoría es el "desplazamiento de celdas". Al copiar una fórmula, si no se usan referencias absolutas, la tasa impositiva (ej: IVA 10%) puede terminar apuntando a una celda vacía o con texto, invalidando todo el reporte fiscal.

Uso Profesional de Nombres de Rango: En lugar de escribir A1:A500, nombramos el rango como Plan_Cuentas. Esto hace que las fórmulas sean legibles y auditables: =BUSCARV(C2; Plan_Cuentas; 2; 0).

2.2 Tipos de Referencias

3. Lógica de Automatización de Asientos

El uso combinado de **SI**, **Y**, **O** y **BUSCARV** permite que el profesional cree un "Libro Diario Inteligente" que valida los datos en tiempo real.

3.1 La Función BUSCARV en el Plan de Cuentas

Esta función es el motor que vincula el movimiento diario con el maestro de cuentas. Permite que, al ingresar un código, el sistema traiga automáticamente el nombre de la cuenta y su naturaleza (Deudora/Acreedora).

// Fórmula Maestra para Conciliación Bancaria:
=SI(ESERROR(BUSCARV(A2; 'Extracto_Banco'!$A$1:$B$500; 1; FALSO)); "Pndte Conciliar ❌"; "Conciliado ✅")

4. Inteligencia de Negocios (Dashboards)

La **Tabla Dinámica** (Pivot Table) es la herramienta más potente de Excel para el resumen de grandes volúmenes de datos. Permite pasar de 10,000 facturas a un resumen de ventas por sucursal en 3 clics.

4.1 Estructura de un Reporte Dinámico

  • **Filtros:** Periodos, Sucursales, Operadores.
  • **Columnas:** Meses, Trimestres.
  • **Filas:** Cuentas Contables, Centros de Costos.
  • **Valores:** Suma de Montos, Promedios, Porcentajes.
📌 REGLA DE ORO: Los datos origen de una Tabla Dinámica nunca deben contener celdas combinadas ni filas vacías. Debe ser una base de datos "limpia".

6. Guía SOS: El Paramédico de Excel

🆘 "QUÉ HACER SI..."

- LAS FÓRMULAS NO SE CALCULAN: Verifica que el cálculo esté en "Automático" en la pestaña Fórmulas > Opciones de Cálculo.

- MI BUSCARV DA #N/D PERO EL VALOR EXISTE: Tienes espacios invisibles en las celdas. Usa la función =ESPACIOS(celda) para limpiar los datos antes de buscar.

- EL ARCHIVO PESA DEMASIADO Y SE CUELGA: Has aplicado formato a toda la columna (65,000 filas). Limpia los formatos innecesarios y usa "Tablas" oficiales de Excel (Ctrl+T).
