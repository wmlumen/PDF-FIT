1. Variables CSS (Paleta de Colores)
Utilizamos variables para asegurar que los verdes de tu logo sean consistentes en todo el sitio.

CSS
:root {
    --primary-green: #0a4d2a; /* Verde oscuro del logo */
    --light-bg: #f4f4f4;      /* Fondo claro */
    --text-color: #333;
    --accent-color: #0d6335;
}

body {
    font-family: 'Segoe UI', Arial, sans-serif;
    background-color: var(--light-bg);
    color: var(--text-color);
    margin: 0;
}

3. Navegación Lateral
Este bloque da estilo a los botones que viste en el diseño.

CSS
.nav-menu {
    display: flex;
    flex-direction: column;
    gap: 15px;
}

.nav-button {
    background-color: var(--primary-green);
    color: white;
    padding: 12px 20px;
    text-decoration: none;
    border-radius: 4px;
    text-align: center;
    transition: background 0.3s ease;
}

.nav-button:hover {
    background-color: #073a20;
}
Notas de Implementación:
Escalabilidad: He usado max-width: 1200px para que el contenido no se estire demasiado en pantallas muy grandes.

Responsividad: Si deseas que esto sea móvil, te recomiendo añadir un media query sencillo para que el grid-template-columns pase de 250px 1fr a 1fr cuando la pantalla sea menor a 768px.

Tipografía: He sugerido Segoe UI por ser una fuente limpia y profesional que combina bien con la seriedad de una institución académica.
