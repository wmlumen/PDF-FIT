> 📖  BLOQUE 1  —  EL PLAN DE CUENTAS DEL SECTOR PÚBLICO

### 1.1  ¿Qué es el Plan de Cuentas y por qué es el lenguaje del Estado?

Imaginemos que el Estado paraguayo fuera un país con 5 millones de habitantes que hablan idiomas diferentes. Sin un idioma común, nadie se entiende. El Plan de Cuentas del Sector Público es exactamente ese idioma común: es el catálogo oficial de todas las cuentas contables que todas las instituciones del Estado paraguayo deben usar obligatoriamente para registrar sus transacciones.

Sin Plan de Cuentas unificado, cada Ministerio registraría el mismo tipo de gasto con diferentes nombres y códigos, haría imposible consolidar la información, y la Cuenta General del Ejercicio sería una ensalada de datos incomparables. Con el Plan de Cuentas, cuando el contador del Ministerio de Hacienda y el contador de la Gobernación del Chaco registran el pago de sueldos, ambos usan exactamente el mismo código: Cuenta 5.1.1.01 — Servicios Personales — Personal Permanente.

| 📌  DEFINICIÓN FORMAL |
| --- |
| El Plan de Cuentas del Sector Público Paraguayo es el instrumento técnico-normativo aprobado por el Ministerio de Hacienda que establece el código, nombre, naturaleza, función y aplicación de cada cuenta contable que deben utilizar todas las entidades del Sector Público No Financiero en el registro de sus operaciones económico-financieras. |

**Estructura del Plan de Cuentas — la lógica del código**

El Plan de Cuentas paraguayo usa una codificación decimal jerárquica de hasta 8 dígitos. Cada nivel del código agrega más especificidad:

| Nivel | Dígitos | Denominación | Ejemplo |
| --- | --- | --- | --- |
| Clase | 1 dígito | Agrupa las grandes categorías del sistema. | 1 = Activo  /  2 = Pasivo  /  3 = Patrimonio  /  4 = Ingresos  /  5 = Gastos |
| Grupo | 2 dígitos | Sub-agrupa por naturaleza dentro de cada clase. | 1.1 = Activo Corriente  /  1.2 = Activo No Corriente  /  5.1 = Servicios Personales |
| Subgrupo | 3 dígitos | Especifica la categoría del activo, pasivo o gasto. | 1.1.1 = Disponibilidades  /  5.1.1 = Personal Permanente |
| Cuenta principal | 4 dígitos | La cuenta contable propiamente dicha. | 1.1.1.1 = Caja y Bancos  /  5.1.1.1 = Sueldos y Salarios |
| Subcuenta | 5-8 dígitos | Desagrega por institución, programa, proyecto o fuente de financiamiento. | 1.1.1.1.001 = Caja Chica / 1.1.1.1.002 = Banco Continental Cta. Cte. |

| ✏️  EJEMPLO 1  —  Leer un código del Plan de Cuentas — de lo general a lo específico |
| --- |
| Supongamos que el sistema SIAF muestra el código: 5.1.1.03.001 |
| Desglose del código: |
| 5  →  Clase GASTOS (todo lo que el Estado gasta) |
| 5.1  →  Grupo SERVICIOS PERSONALES (gastos en personal) |
| 5.1.1  →  Subgrupo PERSONAL PERMANENTE (funcionarios de planta permanente) |
| 5.1.1.03  →  Cuenta BONIFICACIONES Y GRATIFICACIONES (adicionales al sueldo básico) |
| 5.1.1.03.001  →  Subcuenta BONIFICACIÓN POR ANTIGÜEDAD (específica) |
| Significado práctico: Cuando un contador del Ministerio del Interior registra la bonificación por antigüedad de un comisario con 20 años de servicio, utiliza exactamente este código. La DGCP en el MHCP puede ver al instante cuánto gasta CADA institución del Estado en bonificaciones por antigüedad. |
| Aplicación en la gestión: Si el MHCP detecta que una institución está gastando el doble de lo presupuestado en la cuenta 5.1.1.03, puede emitir una circular de alerta o iniciar una auditoría específica en esa cuenta. |

### 1.2  Las grandes clases del Plan de Cuentas — un recorrido práctico

El Plan de Cuentas del Sector Público paraguayo tiene 6 clases principales. Veamos qué registra cada una con ejemplos reales:

| Clase | Nombre | Naturaleza | ¿Qué registra el Estado paraguayo? |
| --- | --- | --- | --- |
| 1 | ACTIVO | Deudora — aumenta con débito | Efectivo en el BCP y bancos comerciales. Créditos fiscales. Bienes inmuebles, vehículos, equipos. Inversiones en empresas públicas (ANDE, ESSAP, COPACO). Obras en construcción (puentes, rutas, hospitales sin terminar). |
| 2 | PASIVO | Acreedora — aumenta con crédito | Sueldos devengados pendientes de pago. Deuda con proveedores. Préstamos internacionales (BID, BM, CAF). Bonos soberanos emitidos. Pasivos contingentes judiciales. |
| 3 | PATRIMONIO NETO | Acreedora — aumenta con crédito | Capital del Estado (bienes heredados históricamente). Resultado del ejercicio. Ajustes patrimoniales por revaluación de activos. |
| 4 | INGRESOS | Acreedora — aumenta con crédito | Ingresos tributarios (IVA, IRE, IRP, IMAGRO). Ingresos no tributarios (tasas, multas). Transferencias corrientes. Préstamos recibidos (son ingresos de financiamiento). |
| 5 | GASTOS | Deudora — aumenta con débito | Sueldos y salarios. Bienes de consumo (medicamentos, combustible). Servicios contratados. Inversión en infraestructura. Pago de deuda externa. |
| 6 | CUENTAS DE ORDEN | Deudora/Acreedora — registros especiales | Garantías recibidas de proveedores. Avales del Estado. Compromisos futuros. Bienes en custodia que no son propiedad del Estado. |

| Transacción 2: Recaudación del Impuesto Inmobiliario Gs. 1.850 MM |
| Débito: 1.1.1.1 — Banco Continental — Cta. Cte. (ACTIVO +)  Gs. 1.850 MM |
| Crédito: 4.1.1.01 — Impuesto Inmobiliario (INGRESO +)  Gs. 1.850 MM |
| Transacción 3: Compra de camión recolector Gs. 920 MM (pendiente de pago) |
| Débito: 1.2.4.3 — Vehículos y Equipos de Transporte (ACTIVO +)  Gs. 920 MM |
| Crédito: 2.1.2.1 — Cuentas por Pagar — Proveedores (PASIVO +)  Gs. 920 MM |
| Transacción 4: Recepción de un préstamo del Banco Nacional de Fomento Gs. 5.000 MM |
| Débito: 1.1.1.1 — Banco Continental — Cta. Cte. (ACTIVO +)  Gs. 5.000 MM |
| Crédito: 2.2.1.1 — Préstamos de Largo Plazo — BNF (PASIVO +)  Gs. 5.000 MM |
| VERIFICACIÓN — Ecuación contable al final del mes: |
| Activo aumentó: +Gs. 1.850 MM (impuesto cobrado) +Gs. 5.000 MM (préstamo) +Gs. 920 MM (camión) -Gs. 4.200 MM (pago sueldos) = +Gs. 3.570 MM |
| Pasivo aumentó: +Gs. 920 MM (factura pendiente) +Gs. 5.000 MM (préstamo) = +Gs. 5.920 MM |
| Patrimonio varió: +Gs. 1.850 MM (ingreso) -Gs. 4.200 MM (gasto sueldos) = -Gs. 2.350 MM |
| Verificación: ΔActivo = ΔPasivo + ΔPatrimonio → +3.570 = +5.920 + (-2.350) = +3.570 ✓ |
