Cobertura del análisis territorial

El cliente municipal complementa el dictamen técnico SNC 551/2023 con la auditoría territorial, ambiental y administrativa municipal. Las consultas de buffer, cruce catastral y restricción hídrica se resuelven en el motor espacial (PostGIS) cuando está configurado; en caso contrario se usa el fallback WFS del Catastro Nacional.

Manual — Municipal PY Pro v1.0

Guía Paso a Paso

  1. Prepare el archivo del fraccionamiento (SHP, DXF, GeoJSON o CSV de coordenadas).
  2. El archivo debe incluir lotes, calles y plazas con sus atributos.
  3. Cargue opcionalmente la planilla de datos con área, frente y uso de cada lote.
  4. Presione "Validar Municipal" para ejecutar el dictamen completo.
  5. Revise el balance de loteamiento: cesión vial 16% y espacios verdes 5-7%.
  6. Genere el Dictamen Municipal o el Dictamen Dual SNC + Municipal.

  • Res. SNC Nº 551/2023 — dictamen técnico complementario

Configuración del motor espacial

Para habilitar el análisis de restricción hídrica y cruce catastral en el backend, defina en el archivo de entorno: PG_HOST, PG_PORT, PG_DATABASE, PG_USER y PG_PASSWORD. Sin estos valores se utiliza el fallback WFS.
